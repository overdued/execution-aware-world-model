==================================================
Task 1 — Command-space Novelty Audit
==================================================

对每个 query future command sequence U[t:t+H]:

1. flatten 为 3H 向量；
2. 只用 train set 拟合 normalization/PCA；
3. 对 A/B/C 计算：
   - nearest-neighbor distance to train
   - kNN mean distance
   - Mahalanobis distance
   - PCA projection
   - 各 axis joint distribution
4. 对每个模型：
   - command-copy
   - ridge
   - M0
   - M1
   - M2
   计算 prediction error 与 novelty score 的关系。

输出：
command_novelty.csv
error_vs_novelty.csv
action_space_pca.png

必须回答：
Q4_combo 是否明显落在 train command manifold 外？
B/C failure 是否随 command novelty 增大？

==================================================
Task 2 — Primitive Composition Baseline
==================================================

实现一个最简单的 compositional baseline：

r_hat =
g_x(state, u_x)
+
g_y(state, u_y)
+
g_w(state, u_w)

优先使用简单 MLP / ridge，不使用 context，不加入复杂 interaction。

所有 g 只使用 train split。
与 command-copy/ridge/M0/M1/M2 在 A/B/C 同一窗口比较。

重点看 B/C：

vx
vy
wz
trajectory endpoint

如果 additive primitive baseline 明显改善 unseen Q4，
记录为 ACTION_COMPOSITION_SIGNAL=SUPPORTED。

不要立刻加入 interaction 网络。

==================================================
Task 3 — Context Disentanglement Probes
==================================================

固定 M1 checkpoint，提取 c_t。

用 train-only linear probe 分别预测：

A. friction condition
B. current vx/vy/wz
C. command family
D. anchor ID（仅诊断）

在 val/test 报告：

R2 / classification accuracy / balanced accuracy。

同时从 M0/M1 的 fast/state representation 做同样 probe（如接口可读）。

目标不是追求高 accuracy，而是回答：

c_t 是否主要编码：
physical condition
还是 current state / command family / episode identity？

输出：
context_probe_results.csv

==================================================
Task 4 — Full Trajectory Consequence
==================================================

使用正确 V0.6.1 physical labels 和合法 quaternion。

实现 task-relevant horizon metric：

Δy

instantaneous velocity error

使用合法姿态/SE(2) 或明确的 valid-planar subset。

比较：
ccopy/ridge/M0/M1/M2。

==================================================

这是 secondary experiment，不影响 Task 1–4 的主结论。
