# V0.6 研究方案：执行预测有效性与上下文可迁移性

日期：2026-09-21  
定位：诊断驱动的小规模方法实验，不是重新从零做一个世界模型，也不是只为通过旧 Context Swap 门而优化。

## 1. 本轮要分开回答的四个问题

| 层级 | 问题 | 决定下一步的证据 |
|---|---|---|
| L0 数据与评价 | 时间、frame、标签、样本独立性正确吗？ | 完整因果审计、node-level manifest、原始高频日志 |
| L1 预测 | 过去信息是否带来超过简单基线的未来预测收益？ | 原生 fixed-origin 预测、逐轴/位姿、Direct/ARX 等比较 |
| L2 上下文 | c 是否能迁移“如何执行”，而不是搬运当前状态？ | 独立 support/query、工况×命令交叉、状态敏感性 |
| L3 视觉世界模型 | 执行表示能否改进视觉未来及任务动作排序？ | 相同 frozen visual encoder 的 Direct vs Execution-aware |

旧 A/B/C/D/E 保留为探索性诊断；不再把“旧 swap 双向显著为正”设为开始任何视觉工程的唯一前提。相反，原生预测和新命令迁移必须成为主门。不得删掉负结果。

## 2. 模型结构：把状态、环境响应、任务后果区分开

### 2.1 因果时间约定

在预测起点 t，所有 predictor 输入的观测时间 ≤t；未来命令序列 U 是起点已给定的候选计划，不是事后从闭环控制器抄来的实际未来行为。

\[
\mathcal H_t=\{o_\tau^p,I_\tau,u_\tau:\tau\le t\},\quad
U_t=(u_{t},\ldots,u_{t+H-1}).
\]

为避免下标错位，实际实现需声明 e[k] 表示 interval 平均执行还是 interval 结束瞬时速度。标签 e_true 仅用作监督；估计速度与 GT 速度分开列出。

### 2.2 当前状态分支

\[
s_t=E_s(o_{t-L_s:t}^{deployable}).
\]

它负责当前速度、姿态、关节、接触等，不应使用未来 actual。暂不强制 s 完全不含工况信息，那是额外假设；要通过 ablation 判断是否真的分工。

### 2.3 上下文分支：从动作—响应 support 中识别条件

\[
\mathcal S_t=\{(s_\tau,u_\tau,s_{\tau+1}) : \tau+1\le t\},\quad
c_t=C_\phi(\mathcal S_t).
\]

第一步保留已有 causal GRU。新增研究对照是：训练时 support 与 query 来自同一稳定工况下的不同时间段或不同 episode，并使用不同命令，检验 c 是否能从一次交互迁移到另一次交互。

\[
\hat E_Q=G_\theta(s_Q,U_Q,C_\phi(\mathcal S_A)),\quad \mathrm{context}(A)=\mathrm{context}(Q).
\]

工况标签可以用于训练分组/采样，但不进入主模型推理。Direct baseline 必须得到相同 support、query current state 和 future command；否则无法归因结构差异。

### 2.4 执行预测：先保持均值模型简单，保留动态递推

候选结构，不是已验证结果：

\[
\hat e_{k+1}=\hat e_k+\Delta t\, f_\theta(\hat s_k,u_k,c_t),\qquad
\hat e_0=\hat e_t^{obs}.
\]

也可继续使用当前 sequence decoder；两者为 ablation，不同时引入 FiLM、mixture、RL 和多种 memory。初始化约束应保持物理连续性：预测从当前状态出发，不是由 c 直接指定一个目标条件的整条模板。

### 2.5 同时评价快速执行与慢速任务后果

快速目标：e[k]=[vx_body,vy_body,wz_body]，保留高频标签和逐轴误差。

慢速目标：使用 GT pose 计算相对位姿：

\[
\Delta T_{t,k}=T_t^{-1}T_{t+k}.
\]

平地可报告平面平移、yaw；姿态明显倾斜时保留 SE(3)，不要将 body wz 的积分直接当作真实 yaw。可以先把短窗口平均速度作为辅助预测，但不能用非因果滤波将未来混入输入，也不能丢弃峰值安全指标。

\[
\mathcal L=\mathcal L_{exec,scaled}+\lambda_T\mathcal L_{relative\ pose}.
\]

两项都必须给 Direct 同等监督，执行标签有尺度归一化时统计只能由训练集拟合。

### 2.6 nominal + residual 是备选 ablation，不是发现新故障真值

\[
\hat E=F_0(\mathcal H_t,U)+\Delta F_\theta(s_t,U,c_t).
\]

F0 在 nominal 数据上学习正常动态并冻结；若用其训练输出构造偏差标签，采用 out-of-fold 或避免训练集拟合误差污染标签。`e-F0` 是相对于所选名义模型的偏差，不等于真实反事实“同一起点正常地面会怎样”。原 r=e-u 保留为有效的 tracking-error 定义，不因新架构出现而宣布旧标签错误。

### 2.7 未来 JEPA 接口

\[
z_t^v=E_{\rm VJEPA2}(I_{\le t}),\quad
\hat z_{t+k}^v=P_\rho(z_t^v,s_t,\hat E_{t:t+k},c_t).
\]

未来目标由冻结视觉编码器产生，仅进入 loss。第一版 3 维速度瓶颈可能丢失 camera pitch/roll、机体高度、接触引起的视角变化；因此未来可扩充为 SE(3) motion tokens + contact，比较 hard bottleneck 与带 command skip 的模型，不能把“删去 u 通路”当作自动证明因果解耦。

目前只准并行验证视频记录、时间戳和离线编码器加载，不启动大规模 JEPA 微调；但也不必等旧 swap 每一项都过关才开始记录 RGB。

## 3. 六组实验

### E0：因果与复现审计（不训练、不采数）

读取原代码和原始数据，导出完整 episode/origin/horizon/pair/seed manifest。复算 command-copy、fixed-origin error-vs-horizon；修复 source–target 共享节点 bootstrap；核查20Hz/50Hz、pre/post-step、frame、relative pose、reset、材质实际读回。所有错误按 evidence/impact/fix 分开记录。

### E1：简单基线与频谱/尺度诊断（先离线）

基线：command-copy；last observed execution；训练集拟合的一阶 lag/ARX；已有 Direct；已有 Context。不要将 action-only learned MLP 视为足够的简单基线。

指标：0.25/0.5/1/2s fixed-origin future；逐轴 MAE/RMSE；相对位姿误差；steady/transition/mixed；按命令族、工况和独立 episode 汇总。不使用 overall mixed-unit L2 作为新主指标。

对 wz 比较 50Hz 原始、正确抗混叠后的20Hz和窗口平均；检查速度、joint/contact 时序与步态相位。若仅波纹难预测而累计方向准确，应改变论文主评价，不应简单“给 wz 更大 loss weight”。

### E2：真正的上下文可迁移性（核心）

构造 support/query：support 在工况 B 下先执行一组动作；query 从固定当前状态和新命令开始。比较：同工况不同命令的 support；异工况但相同命令/phase 的 support；同工况同命令的独立 support；zero/shuffle；仅 state；仅 context。主要问题是“工况相同”还是“动作/状态相似”更决定收益。

对现有 matched-state pair 先做相关性分析；用于物理反事实效果的确认性数据另行采集同一 query anchor 下的多个工况分支。起点需尽可能恢复 base/joints/controller hidden/action queue/gait phase；若无法恢复完整 simulator solver 状态，标为 approximate branch，不声称精确反事实。

### E3：有限新增数据与分布交叉

先 12 条 smoke 校验应用与日志，再最多 240–300 条 pilot，不直接扩3000。

示例预算：4 个 query 命令族 × 8 个独立 anchor × 3 个工况 × 2 个独立重复 =192 条 query；另配约48条独立 support。重复必须区分“同seed重放核验”与“不同噪声seed估计波动”。初始低摩擦不要求总是减速，按实际轨迹评价。

主训练工况可用已验证稳定的1.0/0.6/0.3；0.15为旧OOD分析，不能用它反复调参再声称新颖OOD。额外独立 seed/命令/场景作为确认性 test；插值档位是否新增按预算和安全性预先锁定。

train/val/test 按 anchor、support/query lineage、命令生成器 seed 分组。同一数据用于许多 pair 仍只贡献原来的独立组数。

### E4：小规模公平重训与原因区分

最多4个主要训练配置×3个seed：

1. 等输入 Direct sequence model；
2. 当前 Context architecture；
3. support-query 训练的 Context（必要时同一 decoder，不改容量）；
4. true-friction-conditioned 信息诊断对照（明确 privileged，非部署方案、非保证上界）。

先固定所有模型相同训练数据、history、H、target scales、loss、early-stop规则与调参预算。若主要目标改为相对位姿，所有模型一并增加相同 supervision。

ARX 可CPU拟合，不占主要神经训练配置。nominal-residual/FiLM/NLL 只有结果明确指向相应问题再另批执行。

对已有数据与pilot做受控学习曲线；不得因新训练数据分布与样本量同时改变，就把改善全部归因于规模。

### E5：测试 c 是否可适应与视觉是否有增量（后续，不自动闭环控制）

若 E4 表明 history-conditioned prediction 确有用，可做一个有限 causal context-change 测试，对比 Context、Direct-RNN与简单在线ARX。它是辨别动态适应能力的实验，不以 swap 全部显著为硬性准入。

JEPA主研究仍需证明 vision 增量：未来场景/地形线索与执行状态联合提高预测，且同一控制器的闭环效果随预测改善。视觉不能在隐蔽的、历史也未暴露的摩擦变化前凭空知道工况；报告首次接触前、接触后适应两类任务。

## 4. 统计和评价协议

- 原始旧表保留；新主指标提前冻结，并解释为何不用混合单位 L2。
- 独立 anchor group 是首选统计单元；旧数据缺seed时使用完整 episode lineage，不能用 (source,target) 边当独立节点。
- 明确平均口径：每个 episode、命令族、工况是否等权。测试分布平均与balanced mean同时报告。
- 验证集决定 scaler、阈值、affine、早停；测试集只评价，不用于采样筛最有利子集。
- 每轴误差与不确定性区分；没有概率预测头不报告概率校准已经通过。
- prediction interval calibration 与点预测 amplitude 是不同问题，暂不混用。
- 当前模型胜负可为 INCONCLUSIVE；不强制只输出 PASS/FAIL。

## 5. 决策规则

| 观察 | 下一步 |
|---|---|
| 时间/输入/分片存在错误 | 修复并重建受影响数据，旧数据留档 |
| command-copy/ARX已解决主要任务，Context无增量 | 保留其为强基线；转向视觉后果、长时域/变化场景，或停止这项结构主张 |
| Context只在support与query同动作时有效 | 加cross-support训练、缩减context状态泄漏；不是盲目增大c |
| 当前state敏感性弱、只随c搬运整轨迹 | 重新分配state/context通路，检验initialized rollout |
| teacher friction显著有效、learned c无效 | 问题偏向可辨识性/上下文估计/激励 |
| teacher friction也无效 | 检查目标、波动下限、状态/采样，不能据此认定所有physics context都无价值 |
| 增加独立组后误差持续下降且测试仍不足 | 有依据地扩大数据，保持原协议 |
| 均值已准确但条件波动大 | 再加概率/ensemble与校准，检查风险排序而非只追均值 |

## 6. 时间和算力限制

先做1–2个工作日离线审计。pilot与最多12个训练run预算由前2个run实测，建议单轮上限120个RTX5090 GPU·h、最多300条新增episode，超过需人工批准。这是工作预算而非对实际训练时长的保证。4090可做分析与特征预提取。不要因为8卡可用而一次扫几十种架构。

## 7. 与文献的关系

- IIDA（ICRA 2022）已经研究从 contextual transitions 推断隐式动力学并适应预测；“history→c→dynamics”本身不是新的研究范式：https://arxiv.org/abs/2203.05549 。
- RMA（RSS 2021）提供四足history adaptation的重要参考，但其核心目标是策略适应，不等同于本项目执行后果预测：https://www.roboticsproceedings.org/rss17/p011.html 。
- V-JEPA 2（2025）为冻结视觉表征与动作条件后训练提供基础，后续增量必须通过同输入、同encoder的预测对照证明：https://arxiv.org/abs/2506.09985 。
- Owen & Eckles（2012）讨论交叉随机效应数据的重采样：https://arxiv.org/abs/1106.2125 。

本项目拟验证的价值应落在“跨命令可迁移的执行上下文 + 多尺度物理/视觉后果预测 + 受约束在线修正”，而不是给context改名字或强求一张swap图全绿。
