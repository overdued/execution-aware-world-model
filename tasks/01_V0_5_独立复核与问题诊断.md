## 一、决策摘要

**继续研究，但不直接将当前结果解释为“机制已经证明，只需扩数据修复校准”。下一轮应为 V0.6：预测有效性与上下文可迁移性辨别实验。**

### 2.2 新增零训练基线：预测 actual execution = commanded velocity

利用原缓存的同一行、同一 horizon 直接计算，不拟合任何参数：

\[
\hat e_{t+k}=u_{t+k},\qquad \hat r_{t+k}=0.
\]

表中保留原有 40 步、3 轴展平 L2，仅用于同口径审计；它混合 m/s 与 rad/s，不是建议的论文主指标。

| source subset | Context 原生误差 | command-copy 误差 | 说明 |
|---|---:|---:|---|
| low → normal 配对的 low source | 1.34949 | 1.30862 | Context 没有超过零训练基线 |
| vlow → normal 配对的 vlow source | 1.97611 | 1.75500 | Context 更差 |
| normal → low 配对的 normal source | 1.05783 | 1.14309 | Context 在该 L2 口径有改善 |

low source 的逐轴 MAE：

| 轴 | command-copy | Context |
|---|---:|---:|
| vx (m/s) | 0.07038 | 0.06821 |
| vy (m/s) | 0.06722 | 0.08683 |
| wz (rad/s) | 0.09031 | 0.12935 |

这提示低摩擦 probe 上可能出现：**vx 的微小获益，被模型额外预测的 vy/wz 偏移抵消。** 不能因此断言模型在所有任务不如 command-copy，因为这里只覆盖被匹配选中的 probe；V0 random test 是另一个分布。

为检查重复配对影响，额外按 exact `(future actual, future command)` 去重；这不是 episode 独立化，只是重复窗口敏感性分析。low 共 336 个唯一 source future，Context L2=1.33340，command-copy=1.31182；vlow 共 204 个，分别为 1.89021 与 1.77759。趋势未改变。

证据：`evidence/independent_recomputed_metrics.csv`、`unique_future_window_baselines.csv`。

### 2.3 “Regime teleport”需要直接比较两组预测，不能只比较它们到真值的距离

原报告使用：

\[
\frac{\|\hat e_{A\leftarrow B}-e_B\|}{\|\hat e_{B\leftarrow B}-e_B\|}\approx1.02.
\]

两个预测到同一目标等距，不意味着两个预测相等，更不是统计等效检验。

本次通过缓存中完全相同的 `(actual future, command future)` 查找 native target prediction。重复键对应的原生预测逐元素一致，最大差值为 0；四个 cross 方向均找到完整匹配。此匹配仅恢复 native target prediction，不证明 A/B 历史或物理状态匹配。

| 方向 | mean ||swap prediction - native target prediction|| | 相对于 native target error |
|---|---:|---:|
| N → L | 0.37062 | 27.46% |
| L → N | 0.24295 | 22.97% |
| N → VL | 0.40808 | 20.65% |
| VL → N | 0.26841 | 25.61% |

这支持存在预测相似性，但不能写“预测统计不可分”“完整切换物理机制”。需要预设等效容差、直接距离和状态/工况控制实验。

证据：`evidence/native_target_prediction_direct_distance.csv`。


### 2.4 原报告的“真实工况差距1.22”实际对应另一种距离

这是本次复算发现的**指标解释错误**，不是残差减法错误。

\[
D_{physical}=\|e_B-e_A\|,\qquad
D_{before}=\|e_B-\hat e_{A\leftarrow A}\|.
\]

| 对照 | 原报告称为真实差距的值（实际D_before） | 缓存真实actual-actual距离 | target native预测误差 |
|---|---:|---:|---:|
| N/L | 1.21672 | 1.48531 | 1.34949 |
| N/VL | 1.64653 | 1.88460 | 1.97611 |

因此N/L下“目标工况原生误差1.35大于真实工况差异1.22”的论据不成立：真正比较是1.34949 < 1.48531。N/VL仍有原生误差大于实际差距，但不能用N/L那条误标的数值解释全部失败。

证据：`evidence/independent_recomputed_metrics.csv` 中 `D_before`、`physical_delta`、反向source的 `E_native`。

## 三、当前最重要的统计与解释问题

### 3.1 Cluster=(source_episode,target_episode) 仍未处理共享 episode 的依赖

(A1,B1) 和 (A1,B2) 共享 A1；它们即使属于不同 pair cluster，也仍相关。因此“cluster CI 没变宽”不等于证明独立性已妥善处理。

缓存中 25,772 行仅包含 968 种不同的实际 future 数组；N→L 的 5,510 行来自 424 种 source future、334 种 target future。唯一窗口数也不是独立样本数，因为窗口仍可重叠或来自同一 episode。

**包内没有完整 source/target episode、seed、origin 映射，故本次不能重做可信的 episode/seed CI。** 下一轮必须导出 node-level manifest，使用独立 anchor group 或跨源/目标 episode 的 resampling，并报告 leave-one-episode/seed/probe-out。多向重采样的理论依据可参考 Owen & Eckles，不能机械套一个 cluster 名称。

### 3.2 校准回归的方向不能混淆

原报告拟合的是：

\[
\hat r=a r+b,\qquad a=\operatorname{Cov}(\hat r,r)/\operatorname{Var}(r).
\]

`a<1` 不足以证明模型的条件预测均值失准。教学推导：若 Y=m(X)+ε，E[ε|X]=0，且完美预测器为 m(X)，则

\[
\frac{\operatorname{Cov}(m(X),Y)}{\operatorname{Var}(Y)}=
\frac{\operatorname{Var}(m(X))}{\operatorname{Var}(m(X))+\operatorname{Var}(ε)}<1.
\]

它可能只是不可预测噪声造成的收缩。真正的均值可靠性应检查 `E[Y|prediction]`、预测分箱残差，以及 `Y = a_cal prediction + b_cal`；实际 Huber 训练也不等同于假定的 MSE 最优条件均值，因此需明确估计对象。

从现有 Pearson 与原斜率可推算反向线性斜率（近似，需统一 ddof）：`a_cal = Pearson² / a`。

| 条件/轴 | 原报告 pred-on-truth slope | truth-on-pred slope |
|---|---:|---:|
| low/vx | 0.80545 | 1.03828 |
| vlow/vx | 0.61071 | 0.99302 |
| low/wz | 0.45711 | 0.84933 |

因此，不能仅根据 0.61 就声称 vlow/vx 幅值需要大幅放大。以上反向斜率也只是线性摘要，不证明完全校准。

`mean|prediction| / mean|truth|=1.40` 在审计限定的温和 probe 子集上成立，但不能外推为整个 low-friction 数据的统一 40% 过冲。random test 的大 residual 另有不同分布。

### 3.3 正方向不等于正确的目标拉近

令 p0 为 correct-context prediction，d 为 swap 引起的变化，b 为 target actual：

\[
\|b-p_0\|^2-\|b-(p_0+d)\|^2=
2d^\top(b-p_0)-\|d\|^2.
\]

原 S_dir 比较的是 d 与 `(e_B-e_A)`，不是 d 与真正的预测误差 `(e_B-p0)`。即使方向余弦为正，正交分量、source 原生误差和幅值仍可导致 P_target<0。

在 N→L，5,510 行中有 3,380 行同时满足 S_dir>0、P_target<0。这不是数学矛盾，也不能仅归因于“同一方向上走过头”。

### 3.4 各轴 L2 改善不可直接相加

原报告用各轴 norm difference 解释 overall；这些量非线性且不可加。对可加的平方误差差值重新分解：

| N→L | vx | vy | wz | 合计 |
|---|---:|---:|---:|---:|
| squared target gain | +0.03376 | +0.11009 | -0.51908 | -0.37524 |

wz 确实是此口径的主要负贡献，但 vy 从原 per-axis norm 的负值变成 squared gain 正值。应报告精确可加分解，不能将“vy/wz 都无信息”写成定论。

### 3.5 时间划分需要更细，不等于已经发现实现 bug

`class_tau0.25` 与 `class_tau0.5` 对 25,772 行完全相同；缓存中每窗最小 time-since-change 只有 `{0,1,inf}`，其中 10,682 行全为 inf。

这可由整窗分类、探针固定步段和 origin 量化产生，**尚不能断言代码错**。但它意味着 0.25 与 0.5 秒并非两次实质不同的敏感性检验；起步前无可见 change 的 inf 也不能自动证明已稳态。

下一轮需：按目标 timestep 标记 transition/steady/mixed/unknown；从完整 episode 或命令事件表计算最近 change；分开记录预测 origin、lead time、执行结果时刻；使用 50 Hz 原始日志校验 20 Hz 输出（50/20=2.5，不能盲目整数间隔降采样）。

## 四、仍可能存在而包内不能排除的原因

1. **上下文携带状态而非仅携带动力学。** 同工况交换仍引起显著变化；target native prediction 相似也可能因为 c 把 target 当前速度/步态一起搬入 source。需检查 state-only/context-only bypass、跨 support/query 迁移与当前状态守恒，而非靠 PCA 排除。
2. **配对选择偏差。** matched-state 筛选可能只保留 low friction 下接近 normal 的温和状态，而模型训练主要来自 random 大跳变。匹配 current state 是必要分析，但必须报告接受/拒绝分布和适用域；不能只看 corr(P,D_state)≈0 就排除混杂。
3. **步态相位、roll/pitch、接触与姿态导数处理不足。** 低可预测的 wz 不一定是白噪声；可能是本体输入、采样或标签表达不足。需保留 50 Hz，验证 quaternion 顺序与 frame；倾斜时 body wz 不等于世界 yaw 导数。
4. **固定历史与未来泄漏/时间偏移。** 仅复算 r=e-u 不能验明全部输入因果边界。需在线改变 future truth 保持模型输入不变的干预式单测。
5. **摩擦/执行器应用与 reset 状态未完全控制。** 原 Figure E 的初速差异提示需要核查 base/joint/controller hidden/action queue/contact cache/reset randomization；本包没有足够材料直接定案。
6. **缺少必要基线或输出目标不对齐。** command-copy、last-execution、ARX/一阶响应与等输入 Direct 是必需对照。预测短时控制波纹与预测累计位姿是不同目标，不能用一个 pooled MAE 替代。
7. **确实存在数据覆盖和容量问题。** 这是合理候选，但需要固定架构的学习曲线与训练/验证误差来证明；不能由 68 条训练 episode 直接推导“扩至3000必然解决”。

## 五、建议结论用语

“当前执行条件变化具有可测后果，显式 context 对网络预测产生影响；但 context 的物理专属性、跨状态可迁移性和相对强基线的预测增益仍待验证。V0.5 暴露了命令分布差异、弱基线遗漏、时间划分与统计依赖问题，不能将 NO-GO 单独归因于数据量导致的幅值校准。下一轮以可复核的 support/query 试验和多尺度预测评价区分原因。”
